一个反直觉的统计
高楼症现象
兽医界有个著名的怪现象，叫高楼症。
上世纪80年代，纽约的兽医统计过100多只坠楼猫，约90%都活了下来。
更奇怪的是，7层以上的高处坠落，猫受的伤反而更轻。
今天就让我们从这条下落的猫开始，看看物理学怎么解释这一切。
翻正反射
与生俱来的本领
要解释高空存活，得先认识猫的看家本领——翻正反射。
这是一套与生俱来的本能反应，完全不需要思考和练习。
前庭系统一旦察觉身体失去平衡，它就自动启动。
没有支点怎么转身
角动量守恒
问题来了，半空里没有任何支点，猫是怎么给自己掉头的？
答案藏在角动量守恒里：整体不动，可以分局部来转。
猫把身体对折成前后两半，先收紧前肢让前半身快速翻转，再伸展后腿让后半身慢慢跟上来。
一百毫秒的时间窗
快过一次眨眼
这整套翻身动作有多快？
答案是100毫秒左右，比你眨一次眼还要快3倍。
前半身转完换后半身，弓背、展体、伸出四肢，全部一瞬间完成。
所以慢镜头里的猫，看起来就像凭空拧了一下腰。
越高反而越安全
终端速度的秘密
最后回到开头的悖论：为什么楼越高，猫摔得反而越轻？
猫体重轻，下落时还会舒展四肢增大空气阻力，终端速度只有每小时100公里上下。
相比之下，人类的终端速度接近每小时200公里。
